# Cartography Module in the crafting bay

Rusty requested a cartography module and acknowledged the proposal to retain the
crafting table beside a vanilla cartography table in the existing third bay.
The normal module protocol handles installation, removal and transport; no extra
bay, new persistence format or mandatory Magical Map dependency is introduced.
The crafting table retains local coordinate 0,0,0 and the cartography table uses
1,0,0. The prototype mounting recipe uses three iron ingots, one cartography table
and leather, following the existing field-kitchen upgrade pattern.

Vanilla cartography remains functional without Magical Map. With Magical Map
installed, the same vanilla menu provides atlas creation, binding and extraction.
The existing camp loadout is unchanged until a player installs the new module.
This acknowledges implementation, not publication or deployment.
